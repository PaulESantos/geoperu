# Districts of Peru

An `sf` object containing district-level administrative boundaries of
Peru in the WGS 84 coordinate reference system (EPSG:4326).

## Usage

``` r
peru
```

## Format

An `sf` object with 1,874 rows and four variables:

- departamento:

  Department name.

- provincia:

  Province name.

- distrito:

  District name.

- geometry:

  Polygon geometry.
